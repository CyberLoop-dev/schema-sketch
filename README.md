# 🧩 Schema Sketch

Turn a JSON Schema document into a compact, readable summary.

## ✨ Features
- Lists the schema title, declared type, required properties, and property types.
- Handles nested object properties at a glance.
- Reads local JSON files only; it does not execute or fetch remote content.
- Uses Python's standard library.

## 🚀 Usage
```bash
python schema_sketch.py path/to/schema.json
```

## 📌 Development
Run tests with `python -m unittest -v`.
